# Value Objects y Enums
- Crear Value Objects de identidad (`ActorAuditoriaId`, `PersonaId`).
- Crear Value Objects con invariantes (`CorreoElectronico`, `PeriodoVigencia`).
- Usar enums de dominio para estados finitos (`EstadoCuenta`, `TipoCuenta`).
